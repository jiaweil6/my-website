# Blog

Interactive posts on audio DSP, written in Python. Every code cell is
editable and runs **live in your browser** on an in-browser Python kernel
([Pyodide](https://pyodide.org)), with sound flowing through
[pyquist](https://github.com/gclef-cmu/pyquist) and
[browseraudio](https://github.com/jiaweil6/browseraudio).
